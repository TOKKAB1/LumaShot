# LumaShot

**Снимок. Именно такой, как нужно.**

[English](../README.md) · [Română](README.ro.md) · **Русский**

Приложение для Windows на Python и PySide6. Выделите область экрана, добавьте пометки и скопируйте или сохраните изображение. Интерфейс доступен на **румынском, русском и английском**. Выбранный язык сохраняется.

![Интерфейс LumaShot на русском языке](../assets/interface-ru.png)

## Запуск

Нужны Windows, Python 3.10 или новее и PySide6. Скачайте [LumaShot.py](https://github.com/TOKKAB1/LumaShot/raw/refs/heads/main/LumaShot.py) и выполните в папке файла:

```powershell
python -m pip install PySide6==6.12.0
python LumaShot.py
```

Всё приложение находится в одном Python-файле. Версии `.exe` пока нет. Файл [LumaShot.ico](../LumaShot.ico) необязателен: его можно использовать как значок ярлыка Windows.

## Использование

Нажмите **Новый снимок**, **Print Screen** или **Ctrl+Shift+F9**. Выделите область мышью и выберите инструмент на панели рядом с ней.

| Клавиша | Действие |
|---|---|
| `V` | Переместить область или изменить размер за углы |
| `P`, `L`, `A` | Карандаш, линия, стрелка |
| `R`, `E` | Прямоугольник, эллипс |
| `T` | Текст; Enter подтверждает ввод |
| `H`, `M`, `N` | Выделение цветом, непрозрачная маска, номер шага |
| `Ctrl+Z`, `Ctrl+Y` | Отменить, повторить пометку |
| `Ctrl+C` или `Enter` | Скопировать изображение |
| `Ctrl+S` | Сохранить в PNG или JPEG |
| `Esc` или правая кнопка мыши | Отменить снимок |

При вводе текста Esc сначала отменяет этот текст. При перемещении области пометки остаются на исходных местах экрана.

Папку сохранения можно выбрать в **Настройках**. Главное окно содержит только блок создания снимка, выбор языка и папки.

Значки [Lucide](https://lucide.dev/) встроены в Python-файл и повторно используются после первой отрисовки. Интернет и дополнительный пакет значков не требуются. Лицензии сохранены в [уведомлениях о сторонних компонентах](../THIRD_PARTY_NOTICES.md) и в скрипте.

## Значок в области уведомлений

После закрытия главного окна приложение остаётся в области уведомлений, если она доступна. Для полного закрытия нажмите правой кнопкой по фиолетовому значку и выберите **Выход**.

После замены Python-файла сначала закройте приложение через это меню, затем запустите новый файл. Повторный запуск уже работающего приложения открывает существующее окно.

## Конфиденциальность и ограничения

Приложение не отправляет снимки в интернет и не требует аккаунта. Сохранённое изображение содержит применённые пометки, без скрытого оригинала и истории редактирования. Маска полностью заменяет закрытые пиксели; закрывайте всю информацию, которую хотите скрыть.

Используется стандартный буфер обмена Windows. Его история и облачная синхронизация, если они включены, управляются Windows.

- Один снимок ограничен областью одного монитора.
- OCR, снимки с прокруткой и автоматическое выделение окон пока не реализованы.
- Если сочетание занято другим приложением, используйте одно из доступных сочетаний в главном окне или кнопку создания снимка.
- HDR-мониторы и защищённое видео не проверялись.
- Приложение не добавляет себя в автозагрузку Windows.

Десять локальных тестов проверяют рисование, выделение, переводы и экспорт. Разработка проверялась на Windows с Python 3.14 и PySide6 6.12.0.
