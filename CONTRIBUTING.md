# Contributing to LumaShot

Bug reports, translations and focused pull requests are welcome.

1. Fork the repository and create a branch for your change.
2. Install the dependencies with `python -m pip install -r requirements.txt`.
3. Keep the application usable as a single `LumaShot.py` file.
4. Update the Romanian, Russian and English strings together when adding UI text.
5. Run `python -m unittest discover -s tests -v` on Windows.
6. Describe the change and any manual checks in your pull request.

For capture-related bugs, include display scaling, monitor count, Windows and Python versions, and steps to reproduce. Share only sample screenshots without personal information.

Please contribute only material you have the right to contribute. Original contributions to LumaShot are under the repository's MIT license. Preserve the embedded third-party notices; adding another dependency or asset also requires identifying its source and license.
